🔄 Revisión estratégica honesta
El plan original priorizaba finca raíz como vehículo principal. Con la restricción crediticia real ($73M de préstamo máximo vs. $280M mínimo en el mercado colombiano), esa prioridad cambia:

1° Escalar la consultoría — de 1 cliente a 3–4 clientes BPO ($8–12M/mes certificados). Este es el mayor multiplicador disponible. Con ese ingreso, la segunda propiedad se consigue sola y el portafolio crece más rápido.

2° ETFs (S&P 500) — sin restricción crediticia, sin gestión, 10–12% anual en USD. Más eficiente que finca raíz a tu nivel de patrimonio actual.

3° Finca raíz — mantén Santa Marta (activo comprometido, genera flujo). La segunda propiedad llega naturalmente cuando el ingreso lo permita, no antes.

🔒 Conexión privada con Google Apps Script (recomendado)

Tu sheet NO queda público. Solo el dashboard con tu token secreto puede leer los datos.

Paso 1: En tu Google Sheet → Extensiones → Apps Script
Paso 2: Borra el código existente y pega este script:
function doGet(e) {
  var TOKEN = 'CAMBIA_ESTO_POR_TU_TOKEN_SECRETO';
  if (e.parameter.token !== TOKEN) {
    return ContentService.createTextOutput('Unauthorized');
  }
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var csv = data.map(function(row) {
    return row.map(function(c) {
      var s = String(c);
      return s.indexOf(';') > -1 ? '"' + s + '"' : s;
    }).join(';');
  }).join('\n');
  return ContentService.createTextOutput(csv)
    .setMimeType(ContentService.MimeType.TEXT);
}

Paso 3: Cambia CAMBIA_ESTO_POR_TU_TOKEN_SECRETO por cualquier texto que solo tú conozcas (ej: mitoken2026)
Paso 4: Clic en Implementar → Nueva implementación → Tipo: Aplicación web → Ejecutar como: Yo → Acceso: Cualquier usuario → Implementar
Paso 5: Copia la URL que te dan (https://script.google.com/macros/s/.../exec)
Paso 6: Pégala abajo junto con tu token y guarda.

💡 El sheet permanece completamente privado. Solo quien tenga tu URL + token puede leer los datos.
